# BreakReminder downloads

Builds of BreakReminder, a macOS menu bar app that makes you take real eye
breaks. This repo holds release files only.

## Install

1. Download **[BreakReminder.dmg](https://github.com/CarolusSolis/break-reminder-downloads/releases/latest/download/BreakReminder.dmg)**
   (latest release).
2. Open it and drag **BreakReminder** onto the **Applications** folder.
3. Open BreakReminder from Applications. The first time, macOS says it
   "could not verify" the app (it isn't from the App Store). Click **Done**,
   then go to **System Settings → Privacy & Security**, scroll down, click
   **Open Anyway** next to BreakReminder, and confirm. You only do this once.
4. Look for the eye icon in the menu bar.

Requires macOS 14 or later. The app checks for updates itself and asks
before installing one.
